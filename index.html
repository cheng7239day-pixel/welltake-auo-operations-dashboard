資料品質與使用規則
避免把不同版本 Raw Data 當成完全同口徑

      

        
Official KPI
客戶正式認列值以 Tableau 為準，首頁與主管摘要均使用 Official 7 日結案率。

        
Raw 分析
依檔案內實際 Created Month 分組；7D Rate＝該月建立且已結 Incident 中，7 日內結案的比例。

        
待處理案件
以整份檔案 Site 5.HC 最新狀態建立 Snapshot；切換月份不改變現況母體。檔案外案件無法納入。

        
問題分類完整度
Sub Type / Solution 各月完整度不一致；AI 原因分析應優先使用 Problem Description。

        
Excel 匯入相依性
Excel 解析使用 SheetJS CDN；若公司網路阻擋 CDN，請改用 CSV 匯入。首次開啟不含歷史資料。CSV 可離線匯入。

        
Ticket 主檔
Ticket No 為案件主鍵；重複 Ticket 依 Updated Date / Snapshot Date 取最新；無法判定的衝突須先處理。

        
使用邏輯
Official 回答「結果是多少」；Raw 分析 回答「為什麼會這樣」。

        

          RAG 警示標準

          RAG 僅作為管理視覺提示，不修改 AUO Official KPI 定義。
          

            綠 ≥ 90%
            黃 80–89.9%
            紅 < 80%
          

          
Official 7 日結案率 Target：≥ 90%
